# 归序用户手册（0.1.0 dev）

## 使用前

当前构建是开发验收版。先备份文件，只选择备份副本或专用测试目录。不要选择用户主目录、磁盘根目录、项目源码目录、系统目录或正在同步／占位的云盘目录。

安装/便携版依赖 Microsoft Edge WebView2 Runtime。缺少时应用会显示 Microsoft 官方下载地址，不会静默安装。便携版必须完整解压整个 `Guixu-0.1.0` 目录；不能单独复制 `Guixu.exe`。

## 安全工作流

1. 在“整理工作台”选择目录，确认扫描范围和输出目录授权。
2. 首次建议 `report_only` 或 `copy`；扫描只读，不会修改原文件。
3. 选择内置模板／固定类别，或使用模型生成分类树。新树必须单独批准。
4. 查看每个类别 ID、置信度、证据与解析覆盖；待确认项默认原地保留。
5. 编译计划，核对源、确定性目标和计划 hash。
6. 批准 hash，并在最终确认框明确确认后执行。
7. 在任务报告查看 committed/skipped/conflict/failed 数量与操作日志；可在授权目录导出 JSON/CSV。
8. 撤销会生成新的反向计划和 hash。若文件被外部修改或原位置已占用，归序报告冲突且不覆盖。

暂停是协作式的：当前安全块／文件检查点完成后进入暂停。取消不会强杀用户的 Qwen 服务。异常关闭后，任务会进入需恢复状态，恢复前再次核对源、目标、临时文件和 hash。

## 模型与隐私

- 纯规则：无需模型，完全离线；不能用 `auto_plan`。
- DeepSeek：云服务。先保存 Key 到 Windows 凭据存储，再探测连接/能力；内容出站前必须确认数据类型、scope hash 与预算。
- Qwen：外部本机或可信 LAN 推理服务；归序不下载权重、不配置 CUDA，也不负责停止用户服务。
- 模型只输出允许的类别 ID 和证据。路径、代码、任意目标目录会被结构校验拒绝。

## 本地组件

OCR 随当前锁定构建提供并在运行时校验版本及模型 hash。ffmpeg/ffprobe 与 ASR 未捆绑时，音频仍可读取 metadata，视频／语音内容能力显示 `partial` 或 unavailable。组件只能通过带 manifest、相对路径、逐文件 SHA-256 和许可来源的目录显式导入。

## 数据、升级和卸载

数据位于 `%LOCALAPPDATA%\Guixu`，包括 SQLite 历史、缓存和已导入组件；Key 位于 Windows 凭据存储。安装目录只读资源不会存业务数据。升级前未来迁移会先使用 SQLite backup API 产生备份；新于应用支持版本的数据库会阻止启动。

卸载默认保留历史和设置，也不会删除整理过的目录。清除数据会失去应用内撤销索引，当前必须由用户另行手动处理，不能当作普通卸载步骤。

## 诊断

开发树运行 `.\scripts\doctor.ps1`。冻结版可由支持人员运行 `Guixu.exe --diagnose`；结果写入应用数据目录的 `diagnostics.json`，只包含版本/路径/组件存在性，不含 Key 或文件内容。

遇到问题请保留任务 ID、错误码、阶段报告和数据库备份；不要发送原文件或凭据。已知限制见根目录 `KNOWN_LIMITATIONS.md`。
