# 界面与交互完整设计

> **历史 UI 提示：** 模板/规则导航和多模式新建流程已于 2026-09-20 移除；当前过渡界面见 `docs/LEGACY_PRODUCT_CLEANUP.md`。其余安全审阅与执行界面仍有效。

## 1. 视觉方向：数字档案室

产品不是炫技聊天机器人，也不是传统企业统计后台。它应该像一间现代数字档案室：安静、有序、可靠，但在文件流向与分类树上有识别度。

主要视觉：深墨绿侧栏、暖纸白背景、浅米色分隔、少量青绿操作色、铜棕色档案标签。圆角控制在8～14px；不用满屏胶囊卡片、紫色渐变、发光大脑、机器人插画或无用途统计图。

记忆点是审阅页的「双路径文件行」：每行同时给出原位置与拟归档位置，中间细箭头；文件选中时右侧像展开档案卡一样显示来源证据、类别解释和人工修正。类别树用细线、方形索引与不同文件类型的小色块，而不是繁杂大图标。

ui/DESIGN_REFERENCE.html 是静态视觉说明，使用模拟资料，不能读写文件或调用模型。实现应以本文的交互状态和contracts为准，不把设计稿中的按钮当成已经完成的功能。

## 3. 应用框架与响应

窗口默认以1440×900为设计基准，但实际初始尺寸不得超过可用屏幕减64px；最小1024×680。保留系统窗口边框与标题栏，首版不做脆弱的自绘无边框拖拽。

宽度≥1280：导航208px，工作区自适应，审阅证据栏320px。1024～1279：导航72px图标+tooltip，证据栏变为右侧抽屉；表格优先保留文件名、目标、状态，源路径折叠为次行。纵向滚动只发生在当前主内容或数据表，固定底部操作栏不得挡住最后一行。

支持Windows 100%、125%、150%、175%、200%缩放；保证1024×680逻辑尺寸可操作。所有状态不能只靠颜色区分，配文字／图标。键盘Tab顺序、Esc关闭抽屉、Enter确认普通操作、Ctrl+F搜索当前文件列表；执行和撤销不绑定无确认的全局快捷键。遵循prefers-reduced-motion。

## 5. 工作台首页

顶部小字「LOCAL-FIRST FILE ORGANIZER」，主标题「让文件，各归其位。」旁边显示当前模式：云端分析／仅本机／可信局域网。下方是一个突出的目录选择区域和主按钮「新建整理任务」，而不是一排与用户无关的累计数字。

下半区分当前任务／最近任务。恢复未闭合操作时，置顶一张铜色边线卡「上次整理未正常结束」，主操作“核对并恢复”，副操作“查看已完成项”。没有Key时提示“可先用纯类型模板试跑”，不阻止使用软件。

状态：首次空态／已有任务／正在运行／检测到恢复项／磁盘或数据库错误。数据库错误时只展示诊断，不允许新建可修改文件任务。

## 6. 新建任务页：四段设置，不堆满开关

第一段“整理哪里”：源目录文本框+原生选择按钮；目录树概要；三种扫描方式用单选卡，每卡配一行具体影响。选择保留一级模式后展示保护边界示例。

第二段“整理成什么样”：hybrid／topic／modality单选；模板、指定分类、自然语言三个标签页；深度1～3选择器与“同级最多12个目录”的摘要，高级设置再展开上限。输入自然语言时右边显示规则解释草稿，不在每个键入字符时调用收费API。

第三段“怎么处理”：默认预览后移动；复制时出现必填输出目录；直接移动折叠在高级操作并解释仍会跳过未决项；报告模式强调“不会改变任何源文件”。显示高风险选择的常驻标识，不只弹一次toast。

第四段“模型与隐私”：选择连接，显示文本／视觉／ASR能力；显示最小上传摘要与“查看将发送的样例”。未同意出站前仅允许本地扫描。首次试跑按钮使用最多20个分层样本和report_only。

底部固定栏显示“源目录 · 保留一级 · 最多2级 · 预览后移动”，右侧主按钮“扫描并生成方案”。配置错误的按钮旁直接写出原因；不要让用户点击后只得到“操作失败”。

## 7. 分析页

左侧阶段时间线，右侧文件进度表。分别显示已发现、已解析、规则确定、待AI、待确认、被排除。扫描数量尚未确定时显示发现中的数字，不显示假进度100%。

每行展示解析器、状态、耗时和简短警告。用户可筛选失败项，打开详情后看到“缺少ASR模型”“扫描PDF文字不足”“图片过大”等准确原因。暂停按钮先变“正在安全暂停”，到checkpoint后才变“继续”。

模型限流显示重试倒计时；预算到限显示已耗调用数与可选继续策略；本地模型断线明确不会转云。切换页面不停止任务，关闭程序则走安全暂停退出。

## 8. 分类结构页

顶端显示整理区域切换器，如“根目录文件／学习／工作”。树左侧是可编辑类别，右侧是样本覆盖说明与预计目录路径；树节点显示类别名、解释、样本数，不假称样本数等于全量文件数。

提供添加子类、重命名、合并、删除空草稿节点。所有动作受深度／兄弟数限制，非法名称就地提示。被保护的一级目录使用锁标，不可拖动到别的区域。每个节点选中可看包含／排除条件。

底部主按钮“确认分类结构并继续”，说明此时仍未移动文件。固定模板无需逐节点确认，但整体树仍可预览。修改已经批准的树会提示“将生成新版本并使旧整理计划失效”。

## 9. 审阅页：产品核心

桌面宽屏三部分：左侧220px分类树与状态筛选，中间文件表，右侧320px证据卡；主导航另占208px，在总宽不足时分类树可折叠、证据卡抽屉化。

顶部：标题“审阅归档方案”，副标题源目录与“原文件尚未改变”；右上显示报告模式或预览移动模式。状态标签为“全部／高可信建议／待确认／冲突／已排除”，计数来自后端，不硬编码。

文件表列：复选框、文件与类型图标、原相对路径→目标相对路径、判定来源（规则／AI／人工）、建议等级、操作。长路径保留首尾并在悬停显示完整文本；复制完整路径需用户主动操作。

点击文件右侧证据卡：安全预览；文件信息；当前类别选择器；AI简短理由；引用的文本片段／页码／帧时间；抽样覆盖提示；警告；“采用建议”“改为其他类别”“保留原地”。不给一个夸张的“99%准确”大徽章。

批量操作只作用明确勾选项；支持全选当前页或全选筛选结果，两种数量必须区分。修改类别对不属于目标taxonomy的文件要按区域分组处理，不能跨区域硬塞类别ID。

底部固定执行条：“可执行110项 · 待确认12项将留在原处 · 跳过6项”。主按钮“确认并移动110项”或“确认并复制”；进入最终计划弹窗再次显示目标根、目录数、预计空间、冲突规则、当前plan_hash短码。执行按钮只在计划有效、hash匹配、无阻塞时启用。

实体待确认文件夹是显式二级操作“将选中的待确认项送入待确认目录”，单独编译计划；默认不执行。

## 10. 执行与报告页

执行页显示当前文件、当前字节进度、已完成／跳过／冲突计数，操作日志可展开。暂停／取消使用准确文案：“停止后续处理，已完成的移动不会自动恢复”。取消后提供另一个“撤销已完成项”入口，不能混淆。

报告页显示整理前后目录变化、已操作文件数和可撤销范围，提供“打开结果目录”“导出报告”“预览撤销”。部分失败时标题“整理结束，3项需要处理”，不能绿色全成功。

撤销预览给出可恢复／目标已修改／原位置被占用／文件缺失四类，先展示再确认；退出恢复页面不能清掉未处理冲突。

## 11. 模板页

左侧模态筛选与“内置／我的”，右侧紧凑模板卡。卡片只显示名称、一句用途、类别数量、层级；不在卡片堆全部分类名。选中打开右侧抽屉，展示完整类别树、正反例和能力要求。

操作：使用模板新建任务、复制编辑、导出、导入；内置模板无删除按钮。用户模板编辑器保存新版本，并展示正在使用该模板的历史任务不会改变。

## 12. 规则页

规则列表列为开关、优先级、规则名、条件摘要、动作、适用范围。编辑器使用“全部满足／任一满足”的可视化条件，不让普通用户写脚本。提供测试面板，使用已扫描任务前20项显示命中和冲突，不修改真实文件。

保存前检查类别存在、字段类型、数值范围；同优先级冲突显示橙色解释。提示规则与强制规则在列表用不同文字标识，避免误把启发式提示当绝对条件。

## 13. 模型连接页

两个清晰分组：DeepSeek云端、本地Qwen。配置包含连接名、服务地址、模型ID、Key输入／是否已保存、运行时预设、并发与超时折叠项。已有Key只显示“已保存”，不回填明文。

按钮“测试连接与能力”，结果分项显示文本、图像、JSON与时延。错误给可执行说明：认证失败、地址不通、模型不存在、不支持图像、参数不兼容。不得只是统一红色“网络错误”。

本地预设显示“连接现有服务，不负责下载模型”。地址非loopback时出现“数据会发送到这台局域网服务器”，需信任确认。模型卡只显示实际探测能力，不展示未经验证的性能跑分。

## 14. 设置与资源

分组：默认行为、隐私与出站、资源组件、缓存与历史、诊断与关于。资源页逐项列OCR／ASR／ffmpeg状态、版本、位置、校验结果；支持显式导入离线资源包，不后台偷下大模型。

缓存清理展示缩略图／文本／转写各自大小，不影响源文件；清理任务历史单独提示撤销记录后果。切换完全本机模式会禁用所有云连接的新任务；活动任务若在云调用中，等待当前请求结束并停止下一次出站。

## 15. 组件规格与交互出口

必须实现可复用组件：AppShell、TaskStepper、SourcePicker、ScopeBoundaryPreview、TemplatePicker、PolicyEditor、PrivacyPreview、CapabilityBadges、TaxonomyTree、FileMappingTable、EvidenceDrawer、ExecutionBar、ConflictDialog、TaskTimeline、UndoPreview。

每个组件覆盖loading／empty／ready／error／disabled；disabled带解释。Naive UI只作基础控件，不保留默认品牌蓝紫色。文件类型图标来自lucide，颜色是辅助而非唯一编码。演示样例必须只在开发或静态设计稿出现，生产页面只用真实API。

动效100～180ms用于抽屉、行选中与阶段切换；扫描过程可有轻微进度反馈，不做无限炫光。错误与危险操作无需动画遮掩。Playwright截图必须检查1024、1280、1440宽度及长中文路径、空态、失败态，而不是只截最漂亮的假成功页。
