# 本地解析、AI分类与双模型适配

## 1. 总处理链：按需解析，不全量暴力理解

```text
授权目录 → 快速扫描／真实格式检查 → 元数据级强规则
                                     ├─ 排除／已确定 → 记录
                                     └─ 不确定 → 本地解析／需要时视觉描述
                                                   ↓
                                                FileProfile
                                                   ↓
                          模板或规划好的受限分类树 → AI或规则分类
                                                   ↓
                                      schema＋证据＋类别校验 → 审阅
```

扫描阶段不默认哈希全目录；需要缓存或执行前再计算完整hash。强规则确定的纯类型整理不需要OCR、ASR或调用云模型。全文提取不等于摘要生成；本地无摘要模型时用标题、结构和抽样片段，不伪装成真正的本地语义摘要。

## 2. FileProfile统一结构

包含schema_version、file_id、modality、document_kind、metadata、content_summary、evidence、coverage、warnings、capabilities_used、parser_version。每条evidence有id、kind、text、locator和quality；locator可指page、sheet/rows、paragraph、slide、timestamp或image_frame。

content_summary可以来自本地确定性整理或模型描述，必须标注summary_origin。分类必须引用evidence_ids；证据里没有的确切地点、人物姓名、财务状态不能凭空出现在理由中。

metadata本地可完整保存；发送模型前另建OutboundEnvelope，删除绝对路径、用户名、设备信息、未经授权的GPS等字段。不能把FileProfile整体直接JSON序列化上传。

## 3. 格式支持与解析实现

| 文件 | 首版行为 | 组件／降级 |
|---|---|---|
| JPG／JPEG／PNG／WEBP／BMP | 尺寸、方向、有限EXIF、安全缩略图；必要时OCR／视觉描述 | Pillow；缩略图去EXIF；超大像素受限 |
| GIF | 首／中／末代表帧最多3帧，本地标记动态图 | 不能只凭首帧认定完整内容 |
| TIFF／HEIC／RAW | 首版不承诺内容解析，元数据可显示 | 缺插件时unsupported，不能损坏原图 |
| TXT／MD | 检测编码；按标题和段落抽样；不运行MD中的HTML／脚本 | charset-normalizer；无法解码显示警告 |
| JSON | 限深度读取键、结构与少量样例 | 不把JSON内容当应用配置执行 |
| CSV／TSV | 编码／分隔符、表头、代表性行、规模估计 | 标准csv；保留行号；不是完整统计计算 |
| PDF | pypdf抽取文字；低文本页本地渲染后OCR | pypdf不是OCR；依据S08；加密PDF需用户提供密码，仅本次内存使用 |
| DOCX | 段落、标题、表格；批注／隐藏内容默认不外发 | python-docx；不运行宏／外链 |
| PPTX | 幻灯片标题、文本框、表格、页码 | python-pptx；图片页必要时抽取图片分析，未实现整页渲染时明示 |
| XLSX | 工作表名、表头、分层样例行；只读流式 | openpyxl；data_only可读缓存值但不计算公式；无缓存时标记 |
| DOC／PPT／XLS／宏文件 | 元数据展示并提示转换为现代格式 | 不静默启动Office COM或LibreOffice转换 |
| MP3／WAV／M4A／FLAC | ffprobe元数据、标签；可选本地语音转写 | faster-whisper CPU INT8；无ASR仅metadata，不假装内容已读 |
| MP4／MOV／AVI／MKV | 元数据、有限抽帧、已有字幕、可选音轨转写 | ffmpeg／ffprobe；编码不支持则partial |
| 其他 | 只读metadata，默认exclude from move | ZIP不解包，EXE不执行，PT不反序列化 |

文档类在数据模型中使用modality=document和document_kind=pdf/docx/pptx/xlsx；UI可细分六个文件家族：图片、文本、PDF、Office、音频、视频。

## 4. 三档分析预算

| 项目 | fast | standard默认 | deep |
|---|---|---|---|
| 云端单文件文字上限 | 4,000字符 | 12,000字符 | 32,000字符，仍按模型上下文缩减 |
| PDF选页 | 首尾与标题页最多4页 | 最多12页，首中尾分层 | 先全提取可读文字，最多30页OCR |
| PPT页采样 | 最多6页 | 最多20页 | 最多60页；超过明确覆盖度 |
| XLSX采样 | 最多3表，每表20行 | 最多8表，每表50行 | 最多20表，每表200行；不全量外发 |
| 图片长边 | 960px | 1280px | 1920px |
| 图片视觉数 | 每文件1张 | 静图1张，动态图最多3张 | 最多4个有效裁剪，必须额外预算 |
| 音频ASR | 最多60秒样本 | 最多180秒，首中尾 | 用户明确选择全量转写，可暂停 |
| 视频帧 | 最多4帧 | 最多10帧 | 最多24帧，抽样不等于完整理解 |
| 视频音轨 | 最多60秒 | 最多180秒 | 可选全量ASR |

分页与时间样本使用确定性分层采样，并去掉重复段；记录真实范围和总量。采样页数少不能在UI写“已阅读全文”。文本超过预算时优先标题、首尾、目录、分层片段；长文档跨段主题冲突时转待确认。

单图限制64百万像素；解析子进程标准单文件120秒上限，深度解析可独立延长至600秒。ASR全量转写按时间块checkpoint，不以600秒全局超时杀掉合理长录音；每块60秒音频，执行超时与资源使用分别受控。

## 5. 视觉与音频的能力边界

图片视觉描述仅在文本／metadata不足且模板需要时调用；OCR文字足以说明截图性质时不强制再做一次视觉分析。对照片不能只靠OCR分类，否则无文字风景会全部失败。

音频转写只解决语音语义，不是音乐风格／环境声分类器。没有语音、空白转写、低质量转写时返回不足证据；不能把“无转写”自动等同音乐。歌曲标签可提供候选，但冲突时仍需复核。专用声音分类模型是后续扩展，不伪装成本轮DeepSeek／Qwen已经支持原始音频理解。

视频以抽样帧+字幕／ASR综合；标准流程不向模型发送整个视频。Qwen模型卡有视觉／视频能力不代表每个部署运行时支持video_url等同一字段，因此首版统一使用兼容image_url的抽样帧，运行时原生视频接口留作增强，不作为基础功能依赖。

## 6. 模型适配对象

ModelProfile分四件事：provider（DeepSeek或Qwen本地）、runtime、model_id、capabilities。`QwenLocalAdapter`是业务适配器，`OpenAICompatibleTransport`是协议实现；不能为Ollama、LM Studio、vLLM各复制一套业务分类逻辑。

### 6.1 DeepSeek

截至2026-09-12官方图像文档说明 `deepseek-flash`接受图片，旧 `deepseek-v4-flash-vision-exp` 已下线并由Flash承接。默认推荐模型ID设为deepseek-flash，但用户可编辑并重新探测。官方兼容Chat Completions接口与视觉行为依据S02、S03。

默认base_url=`https://api.deepseek.com`，请求路径`/chat/completions`，Bearer Key只在后端读取。正常分类默认非思考模式，通过经验证的DeepSeek专用参数关闭；当前官方写法是 `thinking:{type:disabled}`，只由DeepSeek适配器添加，不转发给其他服务。依据S04。

先试JSON mode，仍用本地schema验证。供应商没有返回usage时保留null；不要根据token估算伪造账单。模型响应只解析最终content，不依赖或存储思维链。

### 6.2 本地 Qwen3.8-27B

官方模型仓库 `Qwen/Qwen3.8-27B`确认27B视觉语言模型，支持图片和视频理解；依据S09。应用侧不直接加载权重，而连接用户已启动的服务。

连接预设：OpenAI-compatible服务默认`http://127.0.0.1:8000/v1`；Ollama `http://127.0.0.1:11434/v1`；LM Studio常见`http://127.0.0.1:1234/v1`仅作为可编辑预设，不保证每台机器一致。model_id以`/models`和实际服务配置为准，不猜测某个GGUF文件名必然是可调用ID。

Ollama只兼容部分OpenAI API，视觉模型可通过Chat Completions图像块调用；兼容并不等于所有高级字段相同，依据S10。自动探测文本、图像、JSON、最大可用请求及取消。运行时不接受某项参数时记录unsupported，使用明确的降级路径，不随机删除字段直到貌似成功。

本地服务可无Key，但允许用户配置；远程局域网服务需要用户信任确认。只允许显式配置的服务，不在局域网自动扫描。纯本机模式仅允许loopback，关闭云回退、网络模型下载和隐式代理。用户自己启动的模型服务是否还访问外网需另行配置，应用不能替外部进程保证绝对断网。

### 6.3 27B部署资源说明

仅按27B参数粗算：BF16纯权重约54GB；4bit纯权重约13.5GB（十进制），均不含量化元数据、视觉部分差异、KV cache、运行时工作区与上下文开销。不能据此保证某个显卡可流畅运行。桌面工具与模型服务可分机，UI必须把“本机处理”和“可信局域网处理”区分开。

首版只提供硬件诊断与服务连接，不自动为用户选择量化版本、下载权重或改变CUDA。部署模型的真实速度与质量在阶段08单独测量。

## 7. 连接测试与能力表

点击“测试连接”只用内置无隐私文本、几何图形测试图与固定JSON题，不使用用户文件。逐项呈现：可达、认证、model_id、文本、视觉、结构化输出、取消／超时、测得时延。每项为unknown/supported/unsupported/error，不用一个绿色“连接成功”冒充全部能力可用。

探测图像成功后再开放需要视觉的模板；不成功时说明照片／视频语义分析受限。文本服务仍可用于文档与ASR文本分类。能力缓存绑定profile_revision、model_id、base_url，任何变化即失效。

## 8. 云端最小上传与出站预览

默认允许在确认后发送受限文字、去EXIF缩略图、有限视频帧与ASR片段；文件名默认不发，绝对路径永不发，精确GPS默认不发，整份文档／原音频／原视频不发。原图直传是额外高级开关，逐项显示大小和范围，只用于受支持图像；不是一个绕过所有策略的“随便传原文件”开关。

首次任务云分析前展示：目的服务、样本数、文字字符、图片张数、实际示例与估算请求量。提醒提取文字和缩略图本身也可能含敏感内容，“不上传原件”不等于不泄露内容。可排除某文件、修改出站类型、切本地或取消。

本地提取阶段可以做轻量手机号／邮箱／证件号规则提示，但不把它宣传为完备脱敏。禁止未经授权自动将本地失败任务回退到云。

## 9. 分类输出与校验

每次默认一个文件一请求；低成本明确短文本可最多4份同批，但每份有独立file_id与证据边界，返回必须一一对应。默认云并发2、本地1。整批规划使用少量样本而不是把整目录文本拼进一个超级上下文。

输出字段：file_id、taxonomy_id、category_id或null、abstain、model_score或null、evidence_ids、reason、tags、warnings。额外未知字段拒绝；category_id必须在批准树allowlist；reason最多160字符、tags最多5项、证据ID必须存在于本文件profile。

无效JSON可进行一次受限修复请求，仅发送原响应与契约，不追加原文件敏感内容；仍失败转待确认。网络瞬时错误总共最多3次尝试，尊重Retry-After；401／403不重试，参数400只做一次能力降级诊断。修复与重试均计入预算，避免隐形无限重试。

模型自评不是概率：高／中／低可信还要结合证据、覆盖度、冲突与解析状态。定量准确率只来自用户标注评测集，不能拿模型自评分平均值当产品准确率。

## 10. 预算、断点与缓存

默认任务最多500次模型调用；输入token预算1,000,000、输出200,000，用户可在任务设置调整。价格未配置时不显示0元，只显示请求／token和“费用未知”。已配置可信价格表时可设金额预算；发请求前保守预留，完成后按usage结算。调用次数可硬限制；费用估算不是供应商账单保证。

达到预算安全暂停，保留已完成结果，可改为剩余文件留待确认，不自动超额继续。云429退避计时显示在任务页；本地超时建议调小图像／上下文，不能反复无限发送。

每个成功文件结果立即持久化，失败文件独立状态；暂停／恢复只调度未完成项。缓存记录真实命中来源，换模板／规则／模型或隐私政策后按相应层级失效。
