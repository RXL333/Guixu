# Guixu UI Design System

Phase M · 2026-09-22。适用于现有 Conversation 工作区，不改变文件执行、授权、版本或 Undo 契约。

## 视觉基础

唯一基础 token 文件为 `frontend/src/styles/tokens.css`，通过 `main.ts` 在 theme 和 workspace 样式前加载。冷白背景、石墨文字、钴蓝主操作；语义色只表示成功、警告、冲突，不按文件序号随机着色。禁止装饰性渐变、光晕和玻璃背景。

| 用途 | Token / 值 |
|---|---|
| 应用 / 内容背景 | `--bg-app` #f5f6f8 / `--bg-surface` #fff |
| 正文 / 次级文字 | `--text-primary` #1f2329 / `--text-secondary` #667085 |
| 主操作 | `--primary` #356ae6，hover #2f5fd1 |
| 分隔 / 强边框 | #e7e9ee / #d9dde5 |
| 间距 | 4、8、12、16、20、24、32、40px |
| 圆角 | 小控件 6、控件 8、业务卡片 10、输入框 12px |
| 字体 | Segoe UI、Microsoft YaHei、系统 sans-serif；不下载字体 |

## 布局与层级

桌面主布局为 240px 左栏、弹性聊天区、380px 文件区。聊天内容最大宽度 760px。窄窗口收紧右栏，1100px 以下文件面板采用可收起覆盖层，防止挤压输入区。各区域独立滚动；长标题截断但保留完整路径提示。正文不用大卡片包裹，方案、执行结果和撤销预览才使用业务卡片。

文件列表行高 56px。网格采用两列；最多渲染 48 条文件节点，通过上下占位保留滚动范围。聊天默认加载最近 80 条，显式加载更早消息。搜索和选择依据稳定 file_id，不依据当前 DOM 索引。

## 交互约定

- 主操作使用填充蓝色；次要操作使用描边或文字；禁用必须依据真实状态。
- Composer 支持 Enter 发送、Shift+Enter 换行；IME composition 期间 Enter 不发送。高度随内容增长但有上限。
- 文件引用入口打开现有文件面板；引用 chips 可清除，数量来自实际选择。
- 方案版本、执行结果入口联动右侧对应标签页。历史方案不得伪装成当前方案。
- 进行中状态使用不定进度，不编造百分比；失败/不可用不能显示成功。
- 统一 AppDialog 用于确认和重命名，原生 dialog 提供模态焦点约束，Escape 取消并恢复焦点。删除说明必须明确不会操作磁盘文件。
- 图标按钮有可访问名称；选中文件使用文字数量与勾选标记，不只依赖颜色。reduced-motion 关闭非必要动画。

## 设置与历史

模型连接和通用设置通过同一页内导航关联。设置采用分节横向行，诊断细节折叠。历史页显示本地时间与中文状态，保留原有任务恢复/取消和删除安全检查。

## 维护与验收

`theme.css` 保留旧任务页面兼容样式，`workspace.css` 是本阶段工作区覆盖层；尚不能宣称所有历史 CSS 已归一。新页面优先引用 tokens，不继续叠加不同色板。

`/__ui-review` 仅在 Vite DEV 中注册，明确显示“界面验收样例”，不执行真实模型或文件动作，离开时恢复 store。它不是产品演示成功证据，生产构建不得包含该模块。

验收证据保存在 `artifacts/ui/final-polish`。浏览器视口截图不等同于 Windows DPI 或原生窗口验收；原生部分必须另行实测。
