# Post-1.0 Backlog

本文件记录 Feature Freeze 后明确延期的需求。PHASE N 不实现以下项目：

- Local Qwen 正式接入与部署体验；
- 新 AI Provider；
- Vector Search / RAG；
- Watch Folder；
- 长期用户记忆；
- Multi-Agent / 通用 Tool Registry；
- 云同步；
- Redo、级联 Undo、跨 ExecutionRound 的复杂 partial batch；
- Legacy Organizer archival、Legacy Code Cleanup；
- Documentation/Repository Cleanup 与仓库瘦身；
- 自动更新和在线升级服务。

只有影响 1.0 正确性、安全性、稳定性、性能或发布可用性的缺陷，才允许在 Feature Freeze 内进入实现。
