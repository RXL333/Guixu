## 计划中的 1.0 能力

- 持久化对话工作区：文件范围、消息、整理要求、方案版本、执行轮次与历史。
- DeepSeek API 文本和受授权的视觉证据；AI 只提出受限类别与依据，不直接给任意执行路径。
- 方案预览、版本差异、明确批准、安全执行、操作日志与可审计的撤销。
- 执行后继续调整、稳定文件引用、语义证据复用、重启恢复与外部文件变化核对。

## 发布前必须解决

- 真实 DeepSeek 首次整理→执行前修改→v2→批准执行的组合链未通过；见 `P1-003`。
- 执行前重规划失败对仍可见 v1 的状态一致性没有安全回滚；见 `P1-004`。
- 需要在当前最终源码上重跑完整回归、故障/权限/审批/磁盘安全矩阵，并在实际 Windows 桌面复核。
- 需要安装器、干净 Windows 环境验收、产物内容/秘密扫描，以及许可证和签名决策。
