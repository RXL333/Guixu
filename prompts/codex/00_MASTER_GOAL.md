# 总 Goal：从设计包到可验收的 Windows 桌面产品

使用方式：在Codex里打开包含本文件的项目根目录，将下面代码块整体作为Goal输入。Goal命令不是PowerShell命令。若当前界面不支持/goal，使用同一任务正文，但不要声称具有Goal的自动持续生命周期。

```text
/goal 按当前仓库中的设计包，实际实现“归序 Guixu”模块化智能文件整理器，直到满足明确的交付标准，或把真正无法自行解决的外部阻塞准确隔离。不要只写计划，不要在完成几页假数据界面后宣称完成。

先读取 AGENTS.md、START_HERE.md、docs/00_BLUEPRINT.md、docs/11_DELIVERY_PLAN.md 和 PROJECT_STATUS.md。确认工作区现状，保护用户已有改动；本设计默认零起步，但发现已有代码时先局部核对而不是清空重建。随后按 prompts/codex/01_FOUNDATION.md 到 09_RELEASE.md 的顺序推进九阶段，仅按当前阶段定向读取相关文档，不反复全仓扫描。

产品选择已经确定，不再逐项向我确认：Windows EXE；Python3.12后端；Vue3+TypeScript+Vite前端；pywebview EdgeChromium桌面壳；FastAPI本地API；SQLite；优先适配DeepSeek API与本地Qwen3.8-27B兼容推理服务。UI按docs/06_UI_SPEC.md、ui/design-tokens.json与ui/DESIGN_REFERENCE.html设计，不能换成普通紫色后台模板。

完整实现图片、文本、PDF/现代Office、音频、视频的本地预处理；24套模板、明确类别、自然语言分类标准；三扫描模式、三组织策略、三分类引擎模式；两阶段分类树规划与逐文件分类；审阅、移动、复制、报告、任务管理、恢复和撤销。默认值严格读取seed/default-settings.json；schema、OpenAPI、参考SQL和模板种子作为实现契约。

先做只读扫描，再做不依赖AI的安全执行器，然后补解析、分类、模型和完整页面。禁止先接AI直接移动真实文件。模型只能输出受限建议，category_id与证据必须本地验证；执行路径只能由受信代码编译。目录默认最多2层、可设1～3层，层级相对受保护整理区域计算；待确认默认原地保留。

文件安全是不可跳过的完成条件：授权范围、目录保护、no-clobber、完整哈希与文件身份核验、计划hash批准、同名冲突、跨盘copy-verify-publish-delete、持久操作日志、崩溃恢复、撤销冲突、取消不自动回滚。不得自动删除、覆盖、修改未授权目录，禁止未经请求上传真实个人资料。自动化测试只能使用临时目录或artifacts/test-workspaces中的样本。

DeepSeek Key通过应用设置输入，不写源码、文档、截图或日志。本地Qwen只连接外部服务，不自动下载权重、安装CUDA或扫描局域网。模型必须能力探测，真实模型调用与假HTTP服务测试严格区分；云端每次出站必须符合已批准的任务隐私范围与预算。没有Key或模型服务时，继续纯规则、假服务契约与其他不依赖它的开发，并把真实联调标BLOCKED_EXTERNAL。

每阶段实际实现、运行对应测试、修复失败，输出artifacts/reports/phase-XX.md，更新PROJECT_STATUS.md与必要DECISION_LOG。实现细节在不改变冻结需求和安全边界时自行决定，不在每阶段结束反复问我是否继续。进入下一阶段前验证必要依赖；存在文件安全或契约失败不得绕过。权限、真实凭据、缺少Windows或资源授权是外部阻塞，不虚构通过；能独立完成的工作继续推进。

测试按docs/09_TESTING.md执行。开发时只运行受影响范围，阶段出口执行对应测试；最终执行后端测试、前端typecheck/test/build、浏览器E2E和有条件的Windows桌面/跨卷/真实模型测试。UI在1024、1280、1440宽度检查。假数据只允许显式测试或设计参考，产品界面必须连接真实API。禁止为了绿灯删除断言、隐藏失败、提高AI自评分或把不支持格式算解析成功。

最终交付包括：完整可读源码和锁文件、可复现启动/验证/打包脚本、数据库迁移、模板与模型提示词、使用手册、依赖许可、已知限制、阶段报告。具备Windows条件时产出PyInstaller onedir与Inno Setup安装程序，并在无Python/Node的干净Windows环境验收。缺少该环境则交付已验证源码和打包脚本，明确“未完成EXE实机验收”，不可伪造EXE完成。Qwen权重不进入发行包。

不要自动push、清理用户目录、提权或改全局开发环境；确需外部授权时清楚说明。不要无限重试或无边界重构：同一技术路径两次实质性失败后保留证据，尝试一个合理替代，仍失败则记录具体阻塞和恢复动作。完成后总结真实已完成项、测试证据、未完成项和准确运行入口；不要用愿景代替可运行结果。
```

## 推荐控制方式

默认推荐逐阶段运行，以便观察质量和控制额度；总Goal适合愿意让Codex连续推进的情况。官方Goals提供pause/resume等控制，但不能替代权限授权、真实Key或无限额度。中途换模型或新会话时，首先读取PROJECT_STATUS.md及最新阶段报告，不能从记忆猜进度。
