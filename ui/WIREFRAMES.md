以下是结构示意，不是可执行软件。所有计数为版式样例。

```text
│  规则中心      │  │ 选择需要整理的文件夹             │  │
│  任务记录      │  │ [D:\资料________________] [选择]│  │

```

## B. 新建任务

```text
顶部：任务名称 + 返回
步骤：01 设置 ─ 02 分析 ─ 03 分类树 ─ 04 审阅 ─ 05 执行
主列：源目录 → 扫描模式 → 模板／自然语言 → 处理方式
右列：实际目录结构预览 + 被保护一级目录 + 隐私摘要
底栏：保留一级 · 智能混合 · 最多2级     [扫描并生成方案]
```

## D. 审阅工作台

```text
审阅归档方案                 原文件尚未改变   [预览后移动]
全部128 | 高可信110 | 待确认12 | 排除6        [搜索文件]
┌ 类别树 ────────┬ 文件映射 ─────────────────┬ 文件档案 ─────┐

│ 工作          │ □ IMG_…jpg                │ 已分析范围    │
│  项目资料     │ 相册/… → 待确认（不移动） │ [采用／修改]  │
│ 虚拟待确认12  │ …                         │ [保留原地]    │
└───────────────┴────────────────────────────┴───────────────┘
110项可执行 · 12项原地保留       [导出报告] [确认并移动110项]
```

1280以下证据卡改抽屉；1024以下不支持桌面窗口继续缩小，但最大化／系统缩放不能导致底部按钮不可达。

## F. 执行／恢复

执行视图重点是当前文件、已完成数、当前字节、暂停状态。恢复视图重点是源与目标现状和冲突解释；不要把崩溃恢复做成一个无说明的“继续”按钮。报告页对“部分成功”使用中性色而不是纯绿色大勾。
