# 正式上线前验收计划（2026-09-27）

目标：以当前源码和 `artifacts/release-agent-chat` 中的 Windows 便携包为对象，逐项核对 `docs/current/deployment/RELEASE_ACCEPTANCE.md`，给出有证据的上线判定。

顺序与范围：

1. 固定本轮版本和包哈希，复核发行内容、文档链接、诊断及数据目录隔离。
2. 运行后端全量、前端全量与类型/生产构建；再跑安全、可靠性、解析和模型分域验收。
3. 在临时或仓库测试目录运行真实文件系统、真实模型（若连接可用）、故障恢复和 500/1,000/5,000 文件性能场景。测试前后核对源文件数量与指纹，避免接触个人目录。
4. 运行打包应用的真实桌面流程：新建会话、目录列表、普通聊天、方案预览、图片预览、重启恢复；记录窗口尺寸与可观察 UI 行为。文件移动只限隔离样本。
5. 核对安装器、签名、许可证、干净 Windows、多 DPI 等发行条件；无条件时明确标记 BLOCKED/NOT_TESTED，不以源码测试替代。

完成标准：每项命令和 UI 场景有结果、退出状态与证据；阻断项有复现步骤和建议；更新项目状态及发布报告。只有验收矩阵要求的全部发行门都满足，才判定 `RELEASE_READY`。
