# 大目录性能改进（2026-09-27）

## 改动

- 关联大量文件时，用最多 4 个工作线程并行执行路径范围检查和必需的内容指纹读取；数据库读写与返回顺序保持原样。无指纹时继续读取 SHA-256，不削弱授权范围与执行前重验证。
- 恢复核对保留逐文件状态检查，但用一条 SQL 写入共同校验时间与默认活动状态，仅对路径、状态、大小、时间或指纹发生变化的文件写详细投影。
- 新会话的授权目录文件列表按 500 项分页，支持服务端名称/路径搜索及“加载更多”；限制 2,000 的旧接口行为不再隐藏后续文件。搜索请求使用版本检查，避免初始列表覆盖用户搜索。
- 整理方案的逐文件去向每页 50 项，仍可搜索整个已读取方案并预览图片。前端不再一次生成数千个方案行节点。
